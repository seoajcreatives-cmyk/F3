# Project Rules & Protocols

- **Git Commits**: Always ask the user for explicit permission before creating a commit.
- **Commit Messages**: Always append " - Antonia" at the end of the commit message (e.g., `Commit message description - Antonia`).

## Protocolo de Bitácora Técnica (_bitacora/)
- **Al iniciar cualquier tarea:** Consultar `_bitacora/CONTEXTO.md` y leer las últimas líneas de `_bitacora/bitacora.jsonl` para conocer el contexto y tareas recientes del equipo.
- **Al finalizar cada tarea:** Registrar obligatoriamente una nueva entrada en `_bitacora/bitacora.jsonl` con el formato JSON Lines (timestamp, author, task, details, files_affected, notes_for_next). Si hubo cambios en directrices generales, actualizar también `_bitacora/CONTEXTO.md`.
